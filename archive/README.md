# Archive

Thư mục này chỉ dùng để xem lại lịch sử phát triển.

- `workflows/`: các bản workflow từ v1 đến v3.2. URL webhook thật đã được thay bằng placeholder để an toàn khi đưa lên GitHub.
- `development/`: spec, plan, test payload, test output, smoke test và implementation report cũ.

Bản workflow nên dùng hiện tại nằm tại `workflow/Daily-5-Minutes-Brief.json`.
